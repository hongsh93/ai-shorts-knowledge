ai-generator

An internal publishing tool for channels owned by its operator

What it is

ai-generator is a private, command-line tool that runs on the operator's own computer. It publishes videos that the operator produces to YouTube channels that the operator owns and manages. It is not a public application: there is no sign-up, no external users, and no web interface.

What it does

  • Uploads the operator's own videos to the operator's own channels, with title, description, tags and a scheduled publish time.
  • Sets custom thumbnails and uploads caption files for those videos.
  • Updates metadata and checks the processing / publishing status of those videos.
  • Reads performance statistics for the operator's own channels, to decide which topics to make next.

YouTube API Services used

  • YouTube Data API v3: videos.insert, videos.update, videos.list, thumbnails.set, captions.insert, channels.list (mine=true)
  • YouTube Analytics API: reports for the operator's own channels

Each channel is authorized once by its owner (the operator) through Google OAuth. The tool only acts on channels that granted that authorization.

Data handling

The tool does not collect, store, sell or share data about other YouTube users or channels. See the Privacy Policy.
