Privacy Policy

ai-generator · Last updated: October 27, 2026

Who uses this tool

ai-generator is an internal tool used only by its operator to publish videos to YouTube channels the operator owns. It has no other users and offers no public sign-in.

YouTube API Services

This tool uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information is accessed

  • OAuth tokens for the operator's own channels, stored only on the operator's computer, used to upload and manage the operator's own videos.
  • Metadata and statistics of the operator's own videos and channels (titles, video IDs, publish status, view counts, watch time).

What is not accessed

The tool does not access, collect or store personal information of viewers or of any other YouTube users or channels. It does not read comments, subscriber lists, or any other user's account data.

Storage and sharing

  • A local log of the operator's own uploads (video ID, title, upload time) is kept on the operator's computer to prevent duplicate uploads.
  • No data is sold, shared with third parties, or used for advertising.
  • Statistics obtained from YouTube API Services are refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

Data deletion

  • The operator can delete all locally stored data at any time by deleting the stored OAuth tokens and the local upload log on the operator's computer.
  • Any data obtained from YouTube API Services is deleted within 7 days after access to the related channel is revoked.
  • Requests about data deletion can be sent to the contact address below and will be handled within 7 days.

Revoking access

Access granted to this tool can be revoked at any time from the Google account security settings: https://security.google.com/settings/security/permissions. Revoking access stops the tool from acting on that channel.
